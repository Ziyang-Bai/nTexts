# nTexts

[![Build](https://github.com/Ziyang-Bai/nTexts/actions/workflows/build.yml/badge.svg)](https://github.com/Ziyang-Bai/nTexts/actions/workflows/build.yml)

TI-Nspire CX / CX II 的轻量纯文本阅读器，使用 Ndless SDK 构建。

## 功能

- 首页显示最近阅读 10 本，重复打开会更新原书目的阅读进度；也可切换到 Documents 目录浏览器
- 从目录浏览器打开 `.txt` / `.txt.tns` 文件，按 F 输入部分文件名筛选当前目录的书籍，文件夹仍可进入；按 0 清除筛选；兼容通过参数直接打开文件
- 流式读取文本，不一次性载入整本书
- BOM 优先识别 UTF-8、UTF-16 LE/BE；无 BOM 时采样验证 UTF-8，否则按 GB18030 解码；每本书可手动选择 UTF-8、GB18030、UTF-16 LE/BE 或恢复自动检测
- 支持 UTF-8、GB18030、UTF-16（无 BOM 的文件可手动指定）、CRLF、LF、制表符和损坏字节替代显示
- 首次打开按当前字号/边距建立页面索引，尾部空行不单独占页；同次分页复用已测量的字形宽度，翻页也复用本次阅读的字形测量，按键按下后即可更新页面
- 自动识别保守的中、英、法文章标题（如 `Chapitre 2`、`Chapitre IV`）；可设置最多 8 条全局 `*`/`?` 整行通配规则
- 自动保存阅读进度，支持最多 20 个带创建时正文摘要的书签
- 搜索、继续查找、借助页面索引向前查找（包含文件开头的命中）；ASCII 与常见法语重音字母匹配时忽略大小写、保留重音区别（`cote` 与 `côté` 分开），精确高亮当前命中，跨行或跨页时分别显示可见部分
- 按百分比/页码/物理行号/章节目录跳转，支持阅读中直接切换上一章、下一章
- 每次启动首次进入主页、书库和阅读页时显示快捷键提示；H 打开当前界面的提示，Enter/Esc 关闭本次提示，提示页按 0 永久关闭自动提示，设置第 7 项可开启
- 小/中/大字号，浅色/深色/护眼主题，窄/宽边距、自定义章节规则和可保存的简体中文／English／Français 界面语言
- 文件信息显示路径、大小、编码、总行数、总页数及修改时间

正文通过 Ndless 的系统 Graphics Context 使用计算器 OS 字体绘制，UTF-8 会转换为 UTF-16；中文语言版 OS 可直接使用系统中文字形。Firebird CX II 的中文 OS 实测可显示中文、英文和常见法语重音字形；日文、韩文字形有缺字方框，混排时仍按当前字形宽度换行。要阅读这些文字，需要计算器 OS 提供相应字形。

按键：

- 左/右：翻页
- 上/下：按原 TXT 物理行移动
- Ctrl+上/下：跳到首尾
- Ctrl+左/右：跳到上一章/下一章（按识别出的章节标题）
- Menu：功能菜单
- 阅读 Menu 后按 0：选择本书编码；改用不同编码时重建页面索引，从书首继续阅读，书签按原字节位置重新定位
- 主页按 (-)，或阅读 Menu 后选「阅读设置」：设置第 8 项切换简体中文／English／Français，切换后立即保存
- H：打开快捷键提示；Enter/Esc 关闭当前提示，本次启动该界面不再自动提示；提示页按 0 永久关闭自动提示，设置第 7 项可开启
- 书库目录按 F：输入部分文件名筛选本目录 `.txt` / `.txt.tns`，忽略大小写并保留重音区别；按 0 清除筛选，进入子目录后继续使用同一筛选词
- 阅读中按 B：添加书签
- 阅读中按 F：搜索；搜索命中后 Enter/下继续向后查找，上向前查找，Esc 退出搜索模式；跨页命中可左右翻页查看完整高亮
- G：打开百分比、页码、物理行号和章节目录跳转
- Esc：返回书库或上级目录

持久化数据位于 Documents 下的 `nTexts` 数据目录。全局设置、最近阅读、每书状态和页面索引分离保存，并使用 CRC-32 检测损坏。保存时先完整写入临时文件；支持 `rename` 的运行时使用原子替换，无法直接替换目标文件的运行时自动回退到检查过的文件复制。

当前页面索引缓存版本为 8，章节标题按裁剪后的长度保存。版本 4–7 的缓存会在下次打开对应文本时自动重建；编码改变或新增法语章节识别规则后也会重建对应页面索引。全局设置为版本 6，每书状态沿用版本 5：版本 3–5 的旧全局设置会迁移并保留字号、主题、最近阅读、搜索历史和章节规则，版本 5 的语言选择也会保留，自动快捷键提示默认开启。旧教学标记只用于读取旧存档。版本 3–4 的每书状态继续迁移并保留进度和书签，每书编码默认为自动检测。旧进度落在尾部空行时会回到最后一页正文。

搜索词、文件名筛选词与章节规则通过 Ndless 的 `_show_msgUserInput` UTF-16 输入接口读入，搜索词和章节规则以 UTF-16 保存与匹配，文件名筛选仅在本次书库浏览中生效。Firebird 中文 OS 实测英文键输入与搜索可用；直接输入中文、法语重音等非 ASCII 字符取决于计算器 OS 的输入方式，仍需真机验证。中文搜索可复用历史词，常见中文章标题由内置规则识别。

## 开发约定

每个新增用户可见功能都需要同步补充上下文快捷键提示或使用说明。优先放入主页、书库、搜索/阅读页的快捷键提示，或设置里的“使用说明”页。

## 构建

仓库提供了 WSL 构建脚本，会优先使用 `NDLESS_SDK`，其次检查
`$HOME/Ndless/ndless-sdk`，最后从 `PATH` 中的 `nspire-gcc` 定位 SDK；脚本同时兼容 SDK 与 WSL 中 Boost SONAME 不一致的问题：

```sh
chmod +x tools/build-wsl.sh
./tools/build-wsl.sh
```

如果 SDK 位于其他位置：`NDLESS_SDK=/path/to/ndless-sdk ./tools/build-wsl.sh`。

`make test` 运行主机行为测试，覆盖编码切换、存档迁移和文本搜索等路径。

版本和提交标记可在编译时覆盖：`./tools/build-wsl.sh VERSION='Beta Testing v0.0.1' COMMIT_HASH='<git-commit>'`。未指定时分别使用 Makefile 中的发行版本和 `local`；“关于”页面显示版本以及提交哈希的前 12 位。GitHub Actions 会把完整的 `${GITHUB_SHA}` 写入程序。

生成的 `nTexts.tns` 传入计算器后直接运行。文本文件建议命名为 `book.txt.tns`，以便 TI-Nspire 文件系统接受并显示它。

## 清理

```sh
./tools/build-wsl.sh clean
```
